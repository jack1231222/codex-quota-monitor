# FAQ

**Does the app reset or increase quota?** No. It reads quota and monitors public information. Public announcements do not prove a grant to your account.

**Is it free?** Official software releases are free. Optional API providers can charge for X queries or AI analysis. The app does not sell a subscription.

**Is the code open source?** Proprietary source remains private. Third-party components keep their original licenses.

**Why are my quota values old?** Codex may be signed out, busy with an account switch, unavailable, or using a changed protocol. Last successful values keep their timestamps and are labeled stale when appropriate.

**Why does a public search show incomplete coverage?** Source failures, pagination, verification gaps, and freshness are retained. An empty result does not prove that no announcement exists.

**Are all ledger values actual charges?** No. Actual charges, estimates, reserves, and unknown amounts are separate. Reconcile against the provider's official invoice.

**Can I use another provider?** Compatible Responses or Chat Completions endpoints can be configured. Check its API behavior, model access, prices, and privacy terms. Compatibility is not guaranteed for every endpoint.
