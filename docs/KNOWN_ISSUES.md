# Known issues and tested scope

This first release is a beta. The final release notes list the exact package and environments actually tested. macOS 13 or later on Apple Silicon is the target; Intel, mobile devices, and the complete macOS/Codex compatibility matrix are not claimed.

Codex app-server is an external compatibility dependency. Missing Codex, a signed-out account, an unsupported protocol, or source failures can leave values unavailable. Public announcements are independent of account readings.

Paid behavior is validated with offline substitutes. No paid live API generation is performed for release acceptance. Provider-specific response retention, credentials, billing, and compatibility must be verified by the user when enabling a provider. Historical unknown charges remain unknown.

Original public posts, user names, profile names, historical analysis, and imported records retain their original language. Some unusual provider or operating-system errors may use their source language. This is not automatic translation of source content.

Legacy import keeps original data and disables paid calls. A copied record is not proof that its historical cost was settled. The old daily app is retained separately and is not automatically replaced.
